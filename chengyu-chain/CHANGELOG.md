# Changelog

## Unreleased

- 在技能自己的 `cfg/pkg.yaml` 声明 `primebuddy.mode: exclusive` 及 CLI 命令；Buddy 根据包内配置完成整局语音交接，无需新增技能名专用映射。需要支持该配置的 Buddy 源码或后续正式版本。

## 0.1.0 — 2026-10-24

### Features

- 四项可配置 `speech` 播音词：答对鼓励、获胜赞美、升级邀请、失败安慰；答对报本局进度。
- 独立语音成语接龙、同音不分声调/前后鼻音、解释与提示、三级5/7/10次通关、三次明确接错判负。
- 多局连续独占；30秒答题、两次提醒和每局一次援助，120秒无有效回应退出。
- 对齐Buddy的安装向导、模型匹配的中文音色菜单；本地验证完整同音转写。
- CLI持久动作开关及单次覆盖，T1站立准备/难过协议及独立验收门禁。
- 独立模型配置、Buddy 安装默认值、私有结束播报缓存。
- T1/Q1 普通答对、明确接错分别播放开心、难过表情；通关与失败才触发已启用且已验收的身体动作。

### Fixes

- 最后一次有效回答达到通关目标后，不再因无须使用的机器人下一成语无效而阻断获胜。
- TTS 模型切换时推荐匹配的音色，避免 3.1 模型沿用 3.0 默认音色导致 HTTP 400。
- 配置后生成结束播报失败时说明配置已保存，并区分 TTS 合成与音频下载错误。
- 将千问 3.1 ASR 明确返回的 `ASR_RESPONSE_HAVE_NO_WORDS` 作为空识别处理，避免静音触发云接口错误提示；其他接口错误仍按失败处理。

### Compatibility

- Buddy 宿主须包含 `interaction: exclusive` 支持；独立运行不导入宿主包。

### Validation

- 316 项单元测试通过。Q1 上使用合成语音文件完成初级 5 次获胜、进入中级、退出交还 Buddy，以及静音不重复报错的验证。
- Q1 开心摆臂、开心表情和自然归位已完成一次现场验证；难过表情及复位有显示状态反馈，尚未取得人工观感确认。

### Known issues

- 实体动作默认关闭；Q1 失望身体动作资源及非站立转换尚未核实。动作中途取消、游戏内晋级身体联动、中高级通关和修复后的真人麦克风路径仍需现场验证。
- T1 双足、四足仍需分别完成当前版本验收；ROS 冷客户端首个请求偶发无回复问题尚未定位。
- 跨控制器不能同时运行多个独立前端管理实例。
