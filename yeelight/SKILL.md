# 易来灯控

## 适用

打开或关闭一盏灯、一个房间的灯，或用户明确指定的全屋灯光。当前只支持开关，不支持亮度、色温、渐变、闪烁、循环变色或场景。

## 准备

需要已安装并登录的 `yeelight-home`、家庭访问权限和已配置的家庭 ID。准备步骤见 [README](README.md)。

在技能目录使用 `python3 main.py context` 查询目标，使用 `python3 main.py set-power` 执行开关。PrimeBuddy 等宿主可在自己的配置中映射这些普通命令；接入细节见 [宿主调用说明](references/buddy.md)。

## 工作流

1. 读取真实房间与设备清单，使用清单中的名称规划目标。
2. 确认开或关，以及灯具、房间或全屋范围。多个同名或近似候选时先询问；只有用户明确要求全屋时才操作全屋。
3. 名称近音且唯一时，可提出真实名称供用户确认，确认前不执行。
4. 执行前用 `check-power` 预检，使用 `preview-power` 核对用户原话并处理返回的确认问题，再调用开关命令；执行时会再次校验目标。等待状态核实后反馈。

   ```bash
   python3 main.py set-power --power false --scope room --room 厨房
   ```

## 结果

仅在目标状态已核实时报告“已打开”或“已关闭”。控制请求已接受、命令退出或返回部分成功，都不能替代设备状态确认。

## 失败与取消

认证失效时提示重新登录；目标不明时询问房间和灯名。状态未确认时明确说明，不自动重发控制请求，也不继续依赖该结果的任务。

取消等待不代表已发出的灯控请求被撤销；不能承诺停止任务后灯会恢复原状。当前包没有独立的停止或状态命令，不要虚构调用。

## 示例

- “关闭厨房灯”：使用真实清单中的厨房房间，操作该房间的灯。
- “打开客厅的吸顶灯”：同时使用真实房间名和设备名定位。
- “关灯”：目标不明确时先询问，不自行扩大到全屋。
