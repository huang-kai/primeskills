# 点歌台

## 适用

播放一首指定歌曲或某位歌手的歌曲。需要歌手或歌名，至少提供一个；只给出名称且无法判断类别时，先询问。用户明确说“歌曲”“歌名”或用书名号标出标题时，按歌名处理。

## 准备

需要机器人原厂 ROS 环境、有效的 QQ 音乐登录、可用网络和可写运行目录。安装与登录步骤见 [README](README.md)。

播放时长和联动开关使用保存的配置。联动关闭时只播放音乐；不能通过点歌请求擅自开启联动或修改配置。联动可能产生身体运动，需遵守现场操作要求。

## 工作流

1. 确认歌手、歌名及已保存的播放设置；缺少必要信息时先询问。
2. 独立运行时，在技能目录执行现有入口，按实际输入省略未提供的选项：

   ```bash
   python3 main.py play --artist 周杰伦 --song 晴天
   ```

   在 PrimeBuddy 中执行时，先读取 [宿主调用说明](references/buddy.md)，使用已映射到独立 CLI 的播放工具。
3. 等待搜索、取流、缓冲、播放结束和已开启的联动清理。任务未完成时，不提前宣布播放完成。
4. 按真实执行结果回复；需要继续点歌时，再确认下一首的歌手或歌名。

## 结果

只有播放器确认本次播放结束且清理完成，才能报告成功。播放时限从音乐实际开始播放计算；歌曲提前结束时随之结束。不要将请求已提交或音源已取得当成播放完成。

## 失败与取消

登录过期由程序先用原设备身份自动续期，并最多重试一次取流；仅首次登录、缺少刷新凭据或刷新授权也已失效时，才提示运行 `python3 main.py configure` 扫码。网络错误、设备超限或频率限制不应提示重复扫码；设备超限按 QQ 音乐 App 提示处理。配置和播放须使用同一数据目录，升级时保留 `device.json` 和 `credential.json`。无搜索结果、取流失败或状态未确认时说明实际原因，不自动重复点歌或继续依赖任务。取流错误码不能直接解释为需要 VIP。

播放中再次唤醒不保证取消当前歌曲。免唤醒续听由宿主语音会话负责；不要承诺无限续听或已支持跨轮“再来一首”。取消时使用本技能已有的信号处理和 `status/recover` 命令；未确认时保留恢复记录。机型联动限制见 [宿主调用说明](references/buddy.md)。

## 示例

- “听周杰伦的歌”：只提供歌手，播放搜索得到的可用歌曲。
- “播放歌曲《甲乙丙丁》”：只提供歌名，不把标题当作歌手。
- “播放晴天”：类别不明确时，先确认是歌名还是歌手。
